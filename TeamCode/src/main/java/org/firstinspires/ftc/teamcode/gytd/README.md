# GYTD TeamCode Scaffold

This package is the minimal starting point for the `GYTD` robot code.

Current structure:
- `GytdBarebonesTeleOp` - visible FTC OpMode with no hardware dependencies yet
- `drive/` - placeholder package for future drive code
- `intake/` - placeholder package for future intake code

The FTC SDK wiring is intentionally left mostly stock so we can build this out incrementally.
