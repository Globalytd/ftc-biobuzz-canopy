# FTC Middle School Lessons

Audience: Middle school students
Goal: Learn where code goes and how to run the robot
Style: Short steps, simple words

---

## Lesson List

1. `01-project-structure.md`
   - Where each part of code lives
   - What each folder does
2. `02-driver-station-map.md`
   - What students see on Driver Station
   - How code names map to menus
3. `03-run-and-deploy.md`
   - How to build, install, init, run, and stop
4. `LESSON_PROGRESS_TRACKER.md`
   - Where class stopped
   - What changed since last class
5. `Red_Pedro_Shoot_Recovery_Test.md`
   - How to test the Red one-touch Pedro path
   - How to simulate a bump and watch recovery
6. `../controls/BUTTON_CONTROLS_REFERENCE.md`
   - All gamepad1 and gamepad2 button controls in one place
   - Update this file whenever a button control changes

---

## Teaching Rule

- Read one section
- Demo once
- Students repeat
- Check understanding
- Write class notes in tracker
